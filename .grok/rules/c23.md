# C23 is the only compiled language in this tree

This file is always loaded in this repository. It does not replace
[`AGENTS.md`](../../AGENTS.md); it is the short Grok reminder so that rule
cannot get lost behind a long session.

- New program code is C23. Do not add `.py` files, `python3` shebangs, Python
  heredocs, or `python` / `python3` invocations — not as a fallback, optional
  path, or "legacy" exception.
- Operator and test glue is POSIX or bash, or an in-tree C23 helper such as
  `tools/sqlq.c` and `tools/jsonq.c`. Flat JSON fields: grep/sed/awk. Nested
  JSON: `build/bin/jsonq`. SQLite: `build/bin/sqlq`.
- Reuse existing C23 first. Create only what is missing. Prefer deletion and
  composition over a new abstraction.
- Procedure: [`docs/DEVELOPING.md`](../../docs/DEVELOPING.md). Current mission:
  [`docs/work/FORWARD_PLAN.md`](../../docs/work/FORWARD_PLAN.md).
- On any implement / fix / add / patch request, also load the `c23` skill
  (`/.grok/skills/c23/SKILL.md`).
