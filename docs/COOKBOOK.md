One question, one answer. This is the lookup table, not the workflow:
`docs/DEVELOPING.md` is the ORDER you do things in, and you read it once.
Come back here every time you forget the exact incantation.

Every recipe below is checked by `make check-cookbook`. A RUN recipe has
its command executed and its expected token required in the output. An ASK
recipe is one whose command is too slow to run in a lint gate, so only its
existence and readiness are checked. A READ recipe cites code that must
still be tracked and must still contain the symbol named.
