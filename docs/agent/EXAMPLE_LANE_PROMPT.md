# Example parallel assignment

```text
Work in <absolute worktree> at the recorded baseline <full origin/main SHA>.
Follow AGENTS.md, docs/DEVELOPING.md, and docs/agent/LANE_CONTRACT.md.

NORTH STAR
<product-level outcome>

USER OUTCOME
<observable gain>

CURRENT BASELINE
<full origin/main SHA and measured starting fact>

OWNED SURFACE
<disjoint paths>

INVARIANTS
<facts that may not weaken>

ACCEPTANCE
<focused commands and literal verdicts required>

CONTINUATION QUEUE
<next bounded work after this slice>

ESCALATE ONLY IF
<authority or product decision blockers>
```

The prompt contains no derived counts, guessed paths, copied project doctrine,
or claim that handoff automatically publishes the result. The worker returns
the exact commit and evidence using [`LANE_REPORT.md`](LANE_REPORT.md).
