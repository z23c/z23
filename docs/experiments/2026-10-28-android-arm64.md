# Android ARM64 executable acceptance

Date: 2026-10-28. Source base: `86135578df89090594f3c7e9e8aa6517f7145756`
with the Android port changes. Build host: Linux x86-64, AMD Ryzen 7 PRO
8840U. Device: Pixel 3, Qualcomm SDM845, LineageOS 22.2 / Android 15.
Compiler: Android NDK r30, Clang 21.0.0 (16134705), API 35.

Intention: build the existing C23 executable for Bionic, preserve bounded
thread shutdown semantics, and exercise the resulting binary on a device.
This is functional acceptance, not a performance benchmark or a wallet
security assessment.

## Reproduce the focused C23 tests

Run from the repository root on Linux after setting the installed NDK path.
Use the installed build-admission command on managed hosts.

```sh
make ZCL_TARGET=android-arm64 android-acceptance
adb devices
make ZCL_TARGET=android-arm64 android-acceptance-device ANDROID_SERIAL=SERIAL
```

Replace `SERIAL` with the selected device serial. Set `ADB` to the
platform-tools executable if it is not on PATH. The device target recompiles
both C23 programs, pushes them, and runs each with a 30-second timeout.
