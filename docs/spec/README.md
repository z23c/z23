# Specifications

Normative formats and protocols: the C23 Commons package format, the power
node contract, the shared-focus protocol, the sovereign identity layer and
the database schema. Code that reads or writes these formats follows the
specification here; a change to a format changes its specification in the
same commit.

Commands: `discover.wiki`, `discover.read`

- List the specifications with summaries: `z23 wiki spec`.
- Read one: `z23 discover read spec/c23-package-format.md`.
