# Validation

The validation audit matrix: which hash, proof-of-work, Merkle, script, UTXO
and shielded checks run at each stage of block processing, and which stages
defer them.

Commands: `discover.wiki`, `discover.read`

- Read the matrix: `z23 discover read validation/VALIDATION_MATRIX.md`.
