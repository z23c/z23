# comment in tools/lint/check_arm_symbol_single.sh for the defect class and its
# limits). One pair per line, tab-separated. THE LIST MAY ONLY

# preprocessor split as ONE definition, with the strictest

# only because it was copy-pasted into a platform split it
# never needed (the file_service.c ROM-parser fix is the
# reference case), or (b) marking both bodies 'static' when a
# real per-arm implementation is intentional and has no
