# check_command_input_keys.sh — grandfathered read-but-not-declared keys.
#
# Format: "<leaf path> <input key>  # why this read cannot reach this leaf".
# SHRINK-ONLY: a new violation not listed here FAILS the gate, and a line
# whose violation has gone away FAILS too (delete it in the same commit).
#
# Every entry here is one shape: a leaf shares its implementation with
# sibling leaves, the shared function reads a key on a branch this leaf can
# never take, and a purely static per-leaf attribution cannot tell that. Each
# line must name the branch. Anything that is NOT that shape is a real
# uncallable-input bug — declare the key instead of listing it here.
