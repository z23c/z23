# Legacy file-size baseline — lint gate E1 (tools/file_size_policy.c).
#
# The files that already exceeded the 1500-line hard limit when the
# target/buffer/limit policy landed. Format: `<path> <max-loc>`.
#
# SHRINK-ONLY, and this is the whole contract:
#   - a file here that GROWS past its number fails the build;
#   - a file here that reaches 1500 lines or fewer must have its row DELETED
#     (the gate fails and says so, so a fix cannot leave a stale exemption);
#   - a row naming a file the gate no longer scans is stale and fails;
#   - NOTHING is ever added. A new file over 1500 lines fails; it does not
#     get a row here.
#
# `build/bin/file_size_policy --fix` lowers a number to the file's current
# count and deletes rows that are no longer needed. It cannot raise or add.
#
# Files at or under 1500 lines need no entry at all — 801..1500 is an
# allowed band with no paperwork. Generated/tabular code is skipped entirely
# via ALLOWLIST in tools/file_size_policy.c, not listed here.
