# Baseline — models that still hand-maintain multi-column row read indices.
#
# check_model_column_drift (RATCHET) flags any engine/models/src/*.c that reads
# two or more DISTINCT literal column indices through AR_READ_* / AR_COL_*.
# That is the shape where inserting a column in the middle of the SQL column
# list silently shifts every index below it, with no compiler error and no
# test failure — one field reads its neighbour's value and the data still
# looks plausible.
#
# These files predate engine/models/include/models/model_fields.h and are
# recorded here honestly. The gate fails when a file NOT listed here
# introduces the shape, and it ALSO fails when a listed file stops violating
# without its line being deleted. The baseline may only SHRINK; the goal is
# an empty file and the gate flipped to FAIL.
#
# To remove a line: declare that model's fields once in
# engine/models/include/models/def/<model>_fields.def and derive its column
# string, read index and bind position from that one list. Worked examples:
# blog_post.c, market_download.c, tx_index.c.
#
# Per-line exception (for a read that genuinely cannot come from a field
# list, such as an owning heap blob): `// model-columns-ok: <reason>`.
#
# Format: one repo-relative path per line; `#` lines are comments.
