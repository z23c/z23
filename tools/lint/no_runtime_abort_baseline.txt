# check_no_runtime_abort baseline — files in network-reachable code that still
# hold RUNTIME assert()/abort() sites. assert() is LIVE in this
# build (-DNDEBUG is set only for vendored LevelDB), so each of
# these is a process kill on a failed assumption.
# Format: <path> <site-count>.  COUNTS MAY ONLY SHRINK.
#
# Fix a row by returning an error instead: fail the call, log the
# reason with LOG_FAIL/LOG_ERR, and let the caller reject the
# input — then lower (or delete) the number here. Adding a row is
# not a fix. An assertion about a layout or a constant becomes
# _Static_assert, which this gate deliberately does not count.
#
# An abort that is CORRECT (softening it would trade a crash for
# a key compromise or a plaintext leak) does not belong here at
# all — annotate it in place with // abort-ok:<reason>.
#
# core/ is byte-sealed: its rows are counted and frozen, and are
# only editable through the owner unseal ritual (make core-unseal).
